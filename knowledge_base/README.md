# 简历网站知识库

## 用途
归档简历网站建设所需的全部原始资料，供后续开发阶段快速引用，避免重复读取和解析。

## 目录结构

```
knowledge_base/
├── resume/
│   └── 陈宇翔简历.pdf              # PDF版简历原文
├── mini_program/
│   ├── xinggui-prd-extracted.txt   # 星轨成班PRD纯文本（从HTML提取）
│   └── xinggui-manual-extracted.txt # 星轨成班产品说明书纯文本
├── assets/
│   ├── 个人正装照.jpg               # 简历头像素材
│   └── 小程序二维码.jpg             # 星轨成班小程序二维码
├── profile_summary.md              # 核心履历与项目汇总（提炼文档，供生成网站直接引用）
└── README.md                       # 本文件
```
