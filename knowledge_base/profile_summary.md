## 七、核心项目：「星轨成班」小程序

### 7.1 项目概述

「星轨成班」是一款面向高校学生会、社团等学生组织的**值班自动排班微信小程序**。管理员创建值班任务并录入排班规则后，成员各自上传课表，系统依据空闲时间自动生成均衡、无冲突的排班表，替代传统人工排班。

- **状态**：已上线（v1.0）
- **小程序 AppID**：wx4c9b56ad58a05b14
- **载体**：微信小程序

### 7.2 解决的核心痛点

1. **课表录入繁琐**：成员课表字段多、格式杂，逐条手工录入耗时且易错。
2. **人工排班易冲突**：人工核对空闲时间容易漏掉上课时间重叠或连续值班等问题。
3. **信息收集分散**：排班表散落在群聊、文件里，课表还需管理员逐个催收汇总。

### 7.3 主要功能

| 功能 | 说明 |
|------|------|
| 课表智能识别 | 拍照/截图/上传文件（xls/xlsx/csv/pdf），AI 识别课程名、时间与星期 |
| 手动录入课表 | 逐条添加课程，作为识别之外的兜底方式 |
| 自动排班 | 按排班日期、班次、节次与规则自动生成值班表，自动检测课表冲突 |
| 循环排班 | 支持按周循环（只排一周 / 循环 N 周 / 每周循环） |
| 组织与成员管理 | 邀请码加入、成员增删、管理员设置、组织与任务重命名 |
| 排班结果查看/编辑/导出 | 课表式表格展示、单元格点选编辑、导出排班表 |
| 权限管理 | 管理员 / 普通成员 / 游客三级权限 |
| 游客模式 | 未登录可浏览体验，数据仅存本机、不上传云端 |

### 7.4 产品亮点

- **大模型驱动**：以 Kimi 大模型做课表视觉识别与文本结构化，图片、Excel、PDF 都能「读」成可用数据。
- **多格式课表导入**：图片、xls、xlsx、csv、pdf 五种方式，成员按手头材料任选。
- **约束排班算法**：约束满足 + 贪心 + 回溯，兼顾「排得下」与「分得均」。
- **数据本地隔离**：游客不登录不上云，API 密钥只存云端，安全有边界。

### 7.5 技术架构

| 层级 | 技术 |
|------|------|
| 前端 | 微信小程序原生（WXML / WXSS / JS），基础库 3.7.7 |
| 后端 | 微信云函数（wx-server-sdk + Node.js）|
| 数据 | 云数据库（结构化数据）+ 云存储（文件）|
| AI | Kimi (Moonshot) kimi-k2.6 — 课表图片视觉识别、Excel/PDF 文本结构化 |
| 排班算法 | 自研排班引擎（前端 utils/scheduler.js）：约束满足 + 贪心 + 回溯 |

### 7.6 核心设计细节

- **双态登录设计**：「先体验、后登录」，游客可浏览只读内容，需要上云的功能即时拦截引导登录。
- **AI 识别链路**：上传 → 云函数下载转 base64 → 调大模型 → 程序解析校验 → 返回课程表。大模型输出逐行纯文本而非 JSON，降低解析失败率。
- **排班引擎策略**：
  1. 按日期 × 班次生成待排 Slot
  2. 三重过滤候选人（课表时间重叠 / 空闲时段覆盖 / 手动不可排标记）
  3. 难排优先（可用人数越少的 Slot 越先排）
  4. 贪心分配 + 人均岗位数上限控制均衡
  5. 填不满时触发回溯尝试腾位
- **配置自动保存**：输入停止 600ms 自动保存本地、2 秒防抖同步云端。
