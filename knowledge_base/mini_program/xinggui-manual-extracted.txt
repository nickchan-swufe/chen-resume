      一 产品简介
      「星轨成班」是一款面向高校学生会、社团等学生组织的值班自动排班小程序。组织管理员创建值班任务、设定排班规则后，成员各自上传课表，系统依据空闲时间自动排出一张均衡、无冲突的值班表，把过去「手抄课表、人工排班」的繁琐工作交给 AI 与算法完成。
      无需下载、无需注册账号，微信登录即可使用；也可以选择游客体验先看功能再决定是否登录。

        识别课表拍照 / 截图 / Excel / CSV / PDF 一键识别成结构化课表
        自动排班按空闲时间 + 排班规则自动生成，自动规避冲突
        组织协作邀请码拉群，成员各自上传，管理者免于逐一收集

      二 主要功能

          功能说明

            课表智能识别拍照 / 截图 / 上传文件（xls / xlsx / csv / pdf），AI 识别课程名、时间与星期，识别不清的内容标记待确认
            手动录入课表逐条添加课程，作为识别之外的兜底录入方式

            循环排班支持按周循环（只排一周 / 循环 N 周 / 每周循环），后续周按第一周模板复刻
            组织与成员管理邀请码加入、成员增删、管理员设置、组织与任务重命名
            排班结果查看 / 编辑 / 导出课表式表格展示、单元格点选编辑、导出排班表
            权限管理管理员 / 普通成员 / 游客三级权限，配置修改仅管理员
            游客模式未登录可浏览体验，数据仅存本机、不上传云端

      三 产品亮点

        大模型驱动以 Kimi 大模型做课表视觉识别与文本结构化，图片、Excel、PDF 都能「读」成可用数据。
        多格式课表导入图片、xls、xlsx、csv、pdf 五种方式，成员按手头材料任选。
        约束排班算法约束满足 + 贪心 + 回溯，兼顾「排得下」与「分得均」。
        数据本地隔离游客不登录不上云，API 密钥只存云端，安全有边界。

      六 使用场景

        学生会办公室值班部门成员按空闲时间轮值值班室，管理员排好一周后循环复用。
        社团周末轮值周末活动值班，成员上传课表后自动避开上课时段。
        班级事务值日班委轮值、卫生值日等日常排班，均衡分配避免「能者多劳」。
        活动志愿者排班短期活动的多班次人员安排，导出表格一键下发。

      七 常见问题
      识别不准 / 识别出 0 节课怎么办？优先上传清晰、完整的课表截图；截图模糊时可改用 Excel 导入。识别不清的课程会标「?」供人工校正，识别为空会给出明确提示。
      成员还没传课表，能排班吗？不能。排班需要至少一名成员已上传课表，管理员可在「成员管理」页看到「未传课表」人数并跟进，也可代传。
      想每周都按同一张表循环，怎么设？在「排班配置 → 循环排班」开启，并选择循环周数（只排一周 / 循环 N 周 / 每周循环长期）。
      游客模式下数据会上传云端吗？不会。游客数据仅存本机，点击上传 / 识图会立即提示登录，机制上保证「不登录不上云」。
      组织名称或值班任务名称能改吗？可以，管理员可重命名组织与值班任务；组织重命名在「我的组织」页操作。

      八 数据与隐私说明

        数据存储登录用户的数据存储在微信云开发，按组织隔离；游客数据仅存本机，不触碰云端。
        密钥安全大模型 API 密钥只保存在云函数环境变量，前端与源码均不包含，杜绝随包泄露。
        授权与隐私首次使用需阅读并同意《用户协议》与《隐私政策》，昵称头像由用户主动选择/填写。
